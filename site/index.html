The Asciinator for design engineers

Turn any webpage into ASCII you can actually read.

One command. The whole page becomes text — headlines stay headlines, buttons stay buttons, nav stays legible. Only the photographs become art. Paste it into a PR, a Linear ticket, a Claude chat, or a code comment. No screenshots, no file formats. Just text.

$ npx lofi-ascii url stripe.com --width=120 Read the docs

Not a brightness ramp. A wireframe.

Naïve image→ASCII tools turn a dark hero into a solid █ blob. lofi-ascii walks the live DOM, keeps real text as text, draws buttons as boxes, and renders only the image regions — per-tile, edge-aware — so a black phone, a white phone and a pink phone on one page each keep their shape.

url — text-aware

Headless Chrome + DOM walk. Real copy stays readable; only photos become art. The default, and the showcase.

url-image — native

Whole screenshot → ASCII with a dependency-free renderer. The clean, classic Asciinator look. No chafa needed.

render — local files

Any image → ASCII. blocks, braille, pure 7-bit, edge sketch, or 256-color photo. Deterministic and fast.

wireframe — via Claude

Claude looks at the UI and emits a labeled, semantic wireframe — it knows "this is a button" and says so.

compare — A / B

Two URLs or images, side-by-side or stacked. Perfect for before/after and competitive teardowns.

to-png — back out

Render ASCII back to a crisp PNG for Figma, design docs, and READMEs. Round-trips both ways.

It's also a Claude skill

Install once and Claude Code picks the right mode automatically. Just ask in plain English — no flags to memorize.

Talk to Claude

"Make an ASCII wireframe of stripe.com"
"Convert ~/Desktop/figma-export.png to lofi ASCII"
"Compare these two URLs side by side as ASCII"

→ Claude routes to url, render, or a hand-drawn wireframe and pastes the result inline.

Or run the CLI directly

  • render   image file → ASCII
  • url   webpage → text-aware ASCII
  • url-image   screenshot → native ASCII
  • gallery   every style, one input
  • compare   side-by-side A/B
  • components   pre-made ASCII UI blocks
  • to-png   ASCII → PNG for Figma/docs

Install

Node 18+. Bring chafa and Chrome for the full feature set — lofi-ascii doctor checks for you.

install
# try it instantly, nothing to install
$ npx lofi-ascii url stripe.com --width=120

# or install globally
$ npm install -g lofi-ascii
$ lofi-ascii doctor
