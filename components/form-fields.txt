  ┌─────────────────────────────────────┐
  │ Label                               │
  │ Value or placeholder…               │
  └─────────────────────────────────────┘

  Search:
  ┌──────────────────────────────────┐
  │ ⌕  Search…                       │
  └──────────────────────────────────┘

  Textarea:
  ┌─────────────────────────────────────┐
  │ Message                             │
  │                                     │
  │                                     │
  │                                     │
  └─────────────────────────────────────┘

  Select / dropdown:
  ┌─────────────────────────────────┐
  │ State                       ▾   │
  └─────────────────────────────────┘

  Checkbox group:
  ▣ Email notifications
  ▢ SMS notifications
  ▢ Push notifications

  Toggle:
  Notifications      ●━━○

              │           Cancel          │
              └───────────────────────────┘
